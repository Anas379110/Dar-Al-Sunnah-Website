# Dar Al-Sunnah — Hadith & Fiqh Library Platform
**Dar Al-Sunnah — Hadith & Fiqh Library Platform** · Category: Content website
> Project overview and scope; this repository contains documentation only, not implementation source code.

## About the project
A website with a traditional Islamic aesthetic for books of the Sunnah, fiqh, hadith, and tafsir, featuring intelligent search, section filters, and automatically generated smart summaries for each book.

## Highlights
- 10 sections, author listings, and a database of 12 books with a detail pane for each book
- Intelligent search across the books with section filters
- An automatically generated smart summary for each book, presented in a brown and creamy design evoking luxurious antique paper

## Role
Build an Arabic library experience for hadith, fiqh, and tafsir, including book browsing, search, filters, and summaries.

## Technologies used
HTML/CSS/JS, Cloudflare Pages, SSL/HTTPS, SEO, AdSense
