# دار السنة — منصة مكتبة الحديث والفقه
**Dar Al-Sunnah — Hadith & Fiqh Library Platform** · التصنيف: موقع محتوى
> ملف تعريفي بالمشروع ونطاقه؛ هذا المستودع يحتوي على التوثيق فقط ولا يتضمن الشفرة المصدرية.
> Project overview and scope; this repository contains documentation only, not implementation source code.

## نبذة عن المشروع
موقع بأسلوب تراثي إسلامي لكتب السنة والفقه والحديث والتفسير، مع بحث ذكي وفلاتر أقسام وملخصات ذكية مولّدة تلقائياً لكل كتاب.

## أبرز النقاط
- 10 أقسام، عرض للمؤلفين، وقاعدة بيانات من 12 كتاباً مع نافذة تفصيلية لكل كتاب
- بحث ذكي في الكتب مع فلاتر الأقسام
- ملخص ذكي يُولَّد تلقائياً لكل كتاب، بتصميم بني وكريمي بأسلوب ورق قديم فاخر

## الدور
بناء تجربة مكتبة عربية للحديث والفقه والتفسير، مع تصفح الكتب والبحث والفلاتر والملخصات.
